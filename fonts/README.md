Bangers (Regular) and JetBrains Mono (Regular) latin subsets from Google Fonts, both under the SIL
Open Font License 1.1 (see OFL-Bangers.txt and OFL-JetBrainsMono.txt). They are embedded as base64
into the SVGs under assets/ and game/ so the images render inside GitHub's image proxy.

Inter Bold (fonts/Inter-Bold-caps.ttf) is Inter 4.1 from github.com/rsms/inter, subset to the capitals A to Z
with its name table kept, under the SIL Open Font License 1.1 (see OFL-Inter.txt). scripts/shelf.py
outlines it to paths for the book spines in assets/shelf/, so no font ships inside those SVGs.
