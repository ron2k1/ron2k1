Two fonts, both under the SIL Open Font License 1.1. scripts/shelf.py outlines them to paths for the
shelf in assets/shelf/, so no font ships inside those SVGs.

LibreBaskerville-Bold-caps.ttf is Libre Baskerville from github.com/google/fonts (ofl/librebaskerville),
the variable font pinned to weight 700 and subset to the capitals A to Z and the space, with its name
table kept. It sets the book titles. Licence: OFL-LibreBaskerville.txt.

CourierPrime-Bold-label.ttf is Courier Prime Bold from github.com/google/fonts (ofl/courierprime), subset
to A to Z, 0 to 9, the full stop and the space, with its name table kept. It types the call-number
stickers. Licence: OFL-CourierPrime.txt.
